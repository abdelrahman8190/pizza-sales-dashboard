🍕 Pizza Sales Dashboard

An interactive data analytics dashboard designed to monitor and analyze sales performance, customer ordering behavior, and product trends for a pizza retail business. 

The full user interface and visualization layout can be referenced in the repository file: `Screenshot 2026-06-18 030336.png`.

---

 📊 Business Insights & Features

This project transforms raw transactional data into actionable insights, focusing on key performance areas:

* **Revenue Overview:** Tracks total sales metrics (reaching $8,436 as shown in the initial dataset).
* **Product Performance:** Identifies top-selling menu items (e.g., *The Classic Deluxe Pizza* taking the lead with 30 units sold).
* **Size & Category Breakdown:** Visualizes sales distributions, showing that **Large (L)** pizzas account for the highest volume at 40%, while **Classic** and **Veggie** dominate the category distributions.
* **Temporal Trend Analysis:**
  * **Order Trendline of Hours:** Highlights peak operational hours (surging at 12:00 PM and 5:00 PM) to help optimize staffing.
  * **Total Orders Per Week:** Evaluates weekly sales consistency to improve supply chain and inventory management.
* **Dynamic Slicers:** Includes interactive filters for `order_date`, `pizza_category`, and `pizza_size` for deep-dive analysis.
